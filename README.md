# Yecatz

**Stay stressed, dress well.**

一只穿西装、打领带的像素橘猫桌宠。Yecatz 有自己的性格和音乐品味，会陪你聊天、听音乐、查天气，也能阅读文件、换装，并给同一网络里的另一只 Yecatz 传文件。

## 下载与安装

在 [GitHub Releases](https://github.com/YenningC/Yecatz/releases) 页面查找对应系统的安装包。

### macOS

下载 `Yecatz-macOS-arm64.zip`，解压后打开 `Yecatz.app`。需要 Apple 芯片的 Mac 和 macOS 14 或更新版本。

应用尚未经过 Apple 公证。首次打开时如果被系统阻止，在确认下载来源可信后，前往「系统设置 → 隐私与安全性」，选择「仍要打开」。打开后，可以通过菜单栏里的**领带图标**管理 Yecatz。

### Windows

Windows 版目前是开发版本，尚未完成 Windows 实机验证。如果 Release 中已有 `Yecatz-Windows-x64.zip`，下载并解压整个文件夹，然后运行其中的 `Yecatz.exe`。也可以按 [Windows 构建说明](windows/README.md) 自行构建。

Windows 版使用系统托盘菜单，部分动画和功能与 macOS 版存在差异。

## 和 Yecatz 相处

- **单击**：随机挥手、送花或流泪，偶尔触发隐藏动作。
- **双击**：收到粉色爱心和泡泡。
- **拖动**：把 Yecatz 移到喜欢的位置。
- **拖放文件**：普通模式下，把文件拖到 Yecatz 身上，他会播放处理文件的动画，再将文件移入系统回收站或废纸篓。
- **聊天**：通过菜单中的「和 Yecatz 聊天」打开，也可以在鼠标悬浮时点击「…」按钮。
- **阅读文件**：鼠标悬停在 Yecatz 上，点击聊天按钮旁的眼镜图标开启阅读模式，再拖入一个文件，他会用已配置的聊天 API 总结。再次点击眼镜退出。阅读模式下拖入的文件不会进入回收站。
- **每小时一句**：空闲时，Yecatz 会说一句简短的话。macOS 版可在领带菜单中开关。
- **衣橱**：从菜单栏或托盘的「衣橱」选择西装和领带颜色，搭配礼服、燕尾服、手套、口罩、镶钻面罩、围巾、领结或口袋巾。镶钻面罩会闪烁；颈部配饰一次佩戴一种，领结会遮住领带。设置会在下次启动时保留。

聊天里还藏着一个换装彩蛋，发现后可以在衣橱中选择其他穿搭来换回去。

macOS 上按住 Option 再单击可以直接触发隐藏动作。传文件连接期间，普通点击互动和拖放回收站会暂时停用。

阅读模式支持 UTF-8 文本、Markdown、CSV、JSON 等文本文件；macOS 还支持包含可提取文字的 PDF。单个文件最大 5 MB，超过 2 万字时只总结前 2 万字；暂不支持扫描版 PDF、图片和 Word 文件。文件内容会发送给所选聊天 API 服务商，请按需要选择文件。

## 同网传文件

两台电脑上的 Yecatz 可以直接传文件，不需要额外服务器。两台设备必须连接到允许设备互相访问的同一局域网；Mac 与 Windows 代码使用相同的连接方式。

1. 一方在菜单栏或托盘菜单中选择「生成连接码…」，将八位数字连接码**私下**发给对方。连接码有效期为 5 分钟，连接一次后失效。
2. 另一方选择「输入连接码…」，输入八位数字。生成连接码的一方确认连接请求。
3. 连接后，Yecatz 会抱起纸箱。把一个文件拖到自己这边的纸箱上，对方选择保存位置后开始传输；取消保存则拒绝接收。
4. 完成后，选择「断开传输连接」，恢复普通点击互动和回收站功能。

每次可传一个不超过 1 GB 的普通文件，暂不支持文件夹；已有同名文件不会被覆盖。文件分块加密并进行完整性校验。**八位短码安全强度有限**：同一网络上的人可能通过捕获连接数据进行离线猜测，不适合传输敏感文件。请只与可信的人配对，不要公开分享连接码。

双方需要保持在线。正常断开或出错时会清理临时文件；如果程序突然退出或断电，接收目录中可能留下 `.yecatz-*.part` 临时文件，可手动清理。

双方需要使用支持八位码的新版本。设备发现使用局域网 UDP 广播（端口 47857）；校园网可能开启设备隔离或禁止广播，即使连接同一个 Wi-Fi 也未必能直连。连接失败时，请检查网络、局域网权限和防火墙；当前版本不支持跨网络中转或离线接收。

## 聊天与日常任务

Yecatz 的闲聊功能使用 OpenAI 兼容 API。打开领带图标或托盘菜单中的「聊天设置…」，填写 API 地址、模型和密钥。默认地址为 `https://openrouter.ai/api/v1`，默认模型为 `openrouter/free`；使用 OpenRouter 时需要填写自己的 API 密钥。可用服务、模型、额度和费用由所选服务商决定，使用前请查看服务商的说明。

闲聊回复后，Yecatz 会根据最近几轮对话生成两个简短的快捷回复；点击即可发送，也可以在同一个输入框里输入自己的话。如果选项生成失败，输入框仍然可用。生成选项会额外调用一次聊天 API，可能消耗服务商的额度。

使用 OpenRouter 的聊天接口和支持工具调用的模型时，Yecatz 可以按需搜索网页、读取公开网页并结合结果回答。它会尽量核实可靠信息，无法确认时会说明；默认不列出来源，明确要求时可以提供。联网工具由 OpenRouter 执行，可能产生额外费用，即使所选模型本身免费也不代表搜索免费。其他 OpenAI 兼容服务目前仅支持普通聊天，尚未接入此联网工具。

macOS 版也支持配置本地 OpenAI 兼容接口；本地接口可不填密钥。天气和音乐等已支持的内置指令不需要聊天 API。

试着对他说：

- 「今天天气怎么样」或「上海今天天气怎么样」
- 「给我放一首你喜欢的音乐」或「放点音乐」
- 「几点了」或「今天几号」
- 「帮我查一下这个话题的最新消息」或「看看这个网页讲了什么」——需要支持联网工具的配置；读取网页时请提供网址。

macOS 版还支持暂停、切歌、调音量，以及打开浏览器或计算器等命令。音乐文件可放在用户目录的 `Music/Yecatz` 文件夹中；macOS 用户也可以从领带菜单打开该文件夹。天气数据由 [Open-Meteo](https://open-meteo.com/) 提供，天气查询需要联网。

Yecatz 的性格、说话方式和兴趣由 [persona.txt](persona.txt) 中的人设提示词引导；项目并未因此训练或微调模型。修改这个文件后重新构建，即可把更新的人设打包进应用。

## 隐私与权限

- 使用远程聊天 API 时，消息、人设和生成快捷回复所需的最近对话会发送给你选择的服务商。使用阅读模式时，文件的可提取文字也会发送给该服务商。使用网页工具时，搜索请求及网页地址会交由 OpenRouter 和其工具服务处理。
- macOS 版会在 `memory.md` 中保存值得记住的信息，并可能调用 API 更新记忆。可从领带菜单打开、编辑或删除记忆；Windows 版暂不保存长期记忆。
- macOS 版优先将 API 密钥保存在钥匙串；Windows 版使用系统凭据管理器。不要把密钥或个人记忆文件上传到公开仓库。
- 同网传文件可能需要允许局域网访问；macOS 上控制音乐 App 时可能需要自动化权限。

## 检查更新

Yecatz 启动时会联网检查 GitHub 上最新的正式 Release，也可以通过菜单手动检查。发现新版本后，可以打开发布页面自行下载；应用不会自动安装更新。
